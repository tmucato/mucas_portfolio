Leximport

Customs guidance platform that classifies products into HS tariff codes and returns duties and sourced legal excerpts, backed by a RAG pipeline.

leximport · import guidance

Summary

Leximport supports the import workflow. Given a plain language product description, origin country and intended use, it classifies the product against the Harmonized System (HS) tariff codes and returns the applicable duties alongside the excerpts from the official customs tariff that justify the classification.

How it works

The core is a retrieval augmented generation pipeline. The customs tariff PDF is parsed with pypdf and pdfplumber into structured tariff items and legal notes, stored in MongoDB and vectorised into Weaviate for semantic retrieval. A Django REST API exposes a POST /api/import_advice/ endpoint that retrieves, ranks and validates candidate HS codes before returning a grounded answer, with PostgreSQL backing the relational data.

A Next.js frontend lets users submit a product description and view the returned codes, taxes and cited sources, while a companion Flutter app brings the same workflow to iOS and Android.

Delivery

The full stack runs locally with Docker Compose, with Swagger UI for API exploration and automated Django tests covering the API models and endpoints.
