Project Summary

Multi-modal sentiment analysis system combining NLP and Computer Vision to classify sentiment from text and image data. The system processes text using TF-IDF vectorization with NLTK tokenization, while images are processed through EfficientNetB0 feature extraction. Both modalities are then fused using a RandomForest classifier on the combined feature vectors.

The text model achieved 85% accuracy, while the final fusion model reached 78% accuracy with balanced performance across sentiment classes. The project demonstrates effective integration of different data modalities for improved classification performance.

Technologies: Python, NLTK, Scikit-learn, TensorFlow, EfficientNet, OpenCV, Pandas
