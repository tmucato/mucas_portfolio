Multi‑Modal Sentiment Analysis

Classifying sentiment (positive, negative, neutral) from text and image data by combining NLP and computer vision.

View notebook Open in Colab
github.com/tmucato/NLP_CV

Summary

Text is processed with TF‑IDF vectorisation and NLTK tokenisation, while images go through EfficientNetB0 feature extraction. Both modalities are then fused with a random forest classifier on the combined feature vectors.

Results

The text model reached 85% accuracy and the fused model 78%, with balanced performance across sentiment classes. The text model on its own outperformed the fused model, so on this dataset the image features added noise rather than signal. Better image features or weighted fusion are the natural next step.

The notebook covers data preprocessing, model training and results.
