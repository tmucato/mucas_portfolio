Multi-Modal Sentiment Analysis System

Combining NLP and Computer Vision to classify sentiment (positive, negative, neutral) from text and image data.

  1. Home
  2. Portfolio
  3. Multi-Modal Sentiment Analysis

Project information

  • Category: NLP + Computer Vision
  • NLP: TF-IDF + Logistic Regression
  • CV: EfficientNetB0 features + Logistic Regression
  • Fusion: RandomForestClassifier on combined features
  • Accuracy: 0.78 (fusion model)

Objective

The objective was to design and develop a multi-modal sentiment analysis system combining NLP and CV techniques to classify sentiment (positive, negative, neutral) based on text and image data.

Data Preprocessing

Text Data

Loaded with pandas; tokenized with NLTK's word_tokenize; lowercased; stopwords removed; vectorized via Scikit-learn's TfidfVectorizer.

Image Data

Loaded with OpenCV; resized to 224x224; converted to arrays and normalized with EfficientNet preprocess_input for compatibility with the pre-trained model.

Model Architectures

NLP Model

Logistic Regression trained on TF-IDF features for 3-class sentiment.

Computer Vision Model

EfficientNetB0 used for feature extraction; features flattened and fed to Logistic Regression.

Final Fusion Model

Concatenated TF-IDF features and EfficientNet features; RandomForestClassifier trained on combined vectors.

Results and Observations

Text model accuracy: 0.85. Image model initially low (0.32), improved with EfficientNetB0 features but remained moderate. Fusion model reached 0.78 accuracy with balanced precision/recall/F1 across classes.

Challenges

Low initial image accuracy (ResNet50+LR) prompted switch to EfficientNetB0. Careful feature dimension management was required for fusion. Larger datasets increased compute time.

Conclusion

The system effectively combines modalities to improve sentiment classification. Future work includes exploring advanced models and hyperparameter tuning.
