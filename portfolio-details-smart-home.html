Project Summary

AI-powered Smart Home Automation System that controls devices using natural language commands via CLI interface. Users can control lights, fans, and thermostats through conversational commands like "Turn on the light" or "Set fan speed to high", with the system using OpenAI's GPT model to interpret and execute these commands.

The system features an interactive command-line interface that allows real-time device control and status monitoring. It demonstrates practical AI integration for home automation, making smart home control accessible through natural language processing.

Technologies: Python 3.8+, OpenAI API, CLI interface, pytest testing
