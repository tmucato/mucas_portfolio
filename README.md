Tomás Mucato Portfolio
======================

A personal portfolio website showcasing software development and data/AI projects, built with HTML, CSS, JavaScript, and Bootstrap.

Overview
--------
- Focus: Software engineering, data engineering, AI/ML.
- Clean, responsive UI using Bootstrap 5 and vendor libraries (AOS, Swiper, GLightbox, Isotope, Typed.js).
- No build step required; runs as static files.

Live Preview
------------
- Open `index.html` directly in your browser or serve via a simple static server.

Structure
---------
- `index.html` — Landing page (hero, intro, social links)
- `about.html` — Bio, skills, features
- `resume.html` — Summary, education, professional experience, technical skills
- `portfolio.html` — Projects grid with filters
- `portfolio-details-angular-movie.html` — Angular Movie Application details
- `portfolio-details-smart-home.html` — Smart Home Automation AI details
- `portfolio-details-multimodal.html` — Multi‑Modal Sentiment Analysis details
- `contact.html` — Contact information and email form (`forms/contact.php` fallback mailer)
- `assets/` — CSS, JS, vendor libraries, and images

Run Locally
-----------
Option 1: Open `index.html` in a browser.

Option 2: Serve locally (examples):
- Python 3: `python -m http.server 8080`
- Node: `npx serve .`
Then visit `http://localhost:8080` (or the shown URL).
